# 수렴 · 노이즈 정책 (Convergence & Noise) — Phase 4

에이전트 작성자와 에이전트 리뷰어는 **끝없이 돌 수 있다**(E34: 한 PR이 50회 넘게). 이 문서는 리뷰-수정 루프가 끝나게 만들고, 리뷰어가 내는 소음을 **측정**하는 정책 틀이다. 명시된 우선순위는 **진짜 버그 잡기가 먼저, 라운드 줄이기가 두 번째**다(E36) — 라운드를 줄이려고 재현율을 버리지 않는다.

## 1. 왜 루프가 길어지나

- 매 라운드가 **새 버그가 아니라 오래된 버그를 조금씩 더** 꺼낸다(E34: 반복 지적의 약 59%가 처음부터 있던 코드).
- **에이전트 작성자에게 노이즈가 더 비싸다** — 사람은 nit을 넘기지만 에이전트는 커밋 하나를 더 만들고 다음 라운드를 촉발한다(E35).
- "push마다 리뷰" 트리거 + 전체 재리뷰 = 매 라운드 새 표본(같은 모델도 실행마다 다른 것을 찾는다).

## 2. 수렴 장치 (E33)

| 장치 | 정책 문구 틀 | 사용자가 정할 값 |
|------|-------------|------------------|
| C1 **라운드 상한** | {N}라운드 후 리뷰어는 새 발견 대신 "접근 방식 재고"를 요청한다 | N(사례: 3) |
| C2 **diff-only 재리뷰** | {K}회차 이후 재리뷰는 직전 리뷰 이후의 diff만 본다 | K |
| C3 **반복 금지** | 이미 게시된 발견(같은 위치·같은 부류)은 다시 게시하지 않는다 | — |
| C4 **부류 지목** | 같은 부류가 여러 곳이면 부류와 모든 위치를 한 발견으로 낸다 — 작성자가 한 번에 고치게 | — |
| C5 **Pre-existing 분리** | PR이 만들지 않은 버그는 이 루프의 통과 조건이 아니다 → 후속 티켓·야간 리뷰(E38) | 야간 리뷰를 둘지 |
| C6 **응답 의무** | 모든 발견은 수정 또는 사유 달린 resolve(E30) | — |
| C7 **다라운드는 위험 변경만** | 기본은 단일 패스. 여러 라운드는 High 등급에서만(E35) | 등급별 라운드 정책 |

**하드 스톱**(`[HARNESS]`): 상한에 도달하면 자동 루프를 멈추고 사람에게 넘긴다. "한 번만 더"를 자동으로 허용하지 않는다.

## 3. 원천에서 고치기 (E21)

같은 지적이 반복되면 PR마다 고치지 말고 **원천**을 고친다. Phase 4 산출물에 "반복 지적 → 원천" 표를 둔다.

```markdown
| 반복 지적 부류 | 빈도 근거 | 원천 후보 | 결정론화 가능? |
|----------------|-----------|-----------|----------------|
| 에러를 삼키는 catch | 최근 PR n건 | 린트 규칙 | 예 → L2로 이동 |
| 관례 위반(로깅 형식) | | CLAUDE.md 한 줄 | 아니오 |
```

결정론으로 옮길 수 있는 지적은 **L2(CI)로 내리고** AI 리뷰어의 범위에서 뺀다.

## 4. 노이즈 측정 (E36)

| 측정 | 방법 | 무엇을 알려주나 |
|------|------|-----------------|
| N1 **응답 분류** | 모든 리뷰어 코멘트를 작성자 응답으로 분류: `fixed` / `wrong` / `intentional` / `didn't matter` | `wrong`·`didn't matter` 비율 = 소음의 실측 |
| N2 **알려진 깨끗한 PR 실행** | 문제 없는 것으로 확인된 PR에 리뷰어를 돌려 **해로운 변경으로 이어질 오경보**를 센다 | 오경보 비용(특히 에이전트 작성자가 그대로 따를 때) |
| N3 **라운드 분포** | PR별 리뷰-수정 라운드 수 분포, 1회 통과 비율, 5회 이상 비율, 평균 라운드 | 수렴 상태 |
| N4 **부류 반복** | 같은 부류의 지적이 PR을 넘어 반복되는 빈도 | 원천 수정(§3) 대상 |

- 측정 수단(라벨·리액션·스레드 상태·봇 집계)을 **이 저장소에서 실제로 기록 가능한 것**으로 고른다. 기록 수단이 없으면 "측정 불가 — 수단 필요"로 적는다.
- N1 분류는 **작성자가** 한다. 리뷰어가 자기 발견을 분류하지 않는다.
- 비교 대상: Anthropic 수치(E22·E32)는 **목표값이 아니다.** 이 저장소의 **기준선 대비 변화**만 본다(X3).

## 5. 필터 변경은 실험으로 (E13·E37)

리뷰어 프롬프트·필터·모델을 바꿀 때:

1. 바꾸기 전 기준선(N1~N3)을 기록한다.
2. 가능하면 **같은 PR 집합에서 A/B** — 또는 인시던트 eval 세트(metrics-guardrails §3)로 채점.
3. **재현율을 떨어뜨리고 소음만 줄인 변경은 채택하지 않는다**(E36 우선순위).
4. 결과를 기록한다. 효과를 일반화하지 않는다.
