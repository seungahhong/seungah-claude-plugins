# aeo-harness

기술 문서를 **AI 코딩 에이전트**(Claude Code·Cursor·Cline 등)가 찾고, 적은 왕복으로 읽고, 정확히 쓸 수 있게 만드는 것을 **결정론 센서로 측정하고 승인 게이트 뒤에 개선**하는 Claude Code 플러그인입니다.

검색엔진·답변엔진 노출 최적화(SEO/GEO)가 **아닙니다.** 소비자가 사람이 아니라 코딩 에이전트입니다.

## 설치

```bash
claude plugin add seungahhong/seungah-claude-plugins
```

## 한 문장 원칙

> **에이전트가 문서에 도달했다는 것과 그 문서로 코드가 맞아졌다는 것은 다른 사건이다.**

이 둘을 잇는 측정이 아직 없습니다. 이 분야의 근거는 두 덩어리로 끊겨 있습니다 — **발행 측**(llms.txt·robots.txt·마크다운 서빙)은 전부 도달·효율만 쟀고 정확도 측정이 0건이며, **정확도 측**(문서 RAG·예제 코드)은 전부 문서를 이미 쥐여준 조건에서 쟀습니다. 그래서 이 하네스는 둘을 **따로 재고 따로 말합니다.**

## 사용법

```
/aeo-audit
```

첫 질문은 두 개뿐입니다 — **대상 문서가 무엇인가**, **에이전트가 그 문서를 어떤 경로로 얻는가**(HTTP 페치 / MCP 도구 / 저장소 안 파일 / 패키지 설치본). 두 번째 답이 조사의 절반을 결정합니다.

### 4단계

| Phase | 하는 일 |
|---|---|
| **1 도달 조사** | **링크 지도가 있는가**(1급) · JS 없이 본문이 보이는가 · `.md`/`Accept` 협상 · 죽은 링크·앵커 · 벤더 UA replay 오차단 · robots.txt 보고 · 토큰량 census |
| **2 내용 조사** | 심볼별 **예제 존재** · **예제 실행 검증** · 문서↔코드 시그니처 드리프트 · **거짓으로 판정되는 서술** · 대상 심볼의 낯섦 · 주입 표면 |
| **3 개입 계획** | **T-A 위험 0**(거짓 제거) → **T-B 검증 통과분만 반영** → **T-C report-only**(만들지도 고치지도 않음). 계획 승인 + 항목별 개별 승인 |
| **4 수용 증명** | 문서 점수가 아니라 **재측정된 태스크 결과**. 못 돌리면 UNVERIFIED |

## 조사에서 교정된 통념

출발점 글의 주장을 1차 출처로 전부 대조한 결과입니다. 근거는 [`references/evidence.md`](skills/aeo-audit/references/evidence.md)에 F번호로 정리돼 있습니다.

| 흔한 말 | 1차 출처가 말하는 것 |
|---|---|
| "문서는 15,000 / 25,000 / 20,000 토큰 이하로" | 인용된 논문에 **그 문자열이 없다.** 논문은 "이 연구는 토큰 소비나 문서 크기를 측정하지 않았다"고 적는다 |
| "llms.txt를 만들면 AI 가시성이 오른다" | 파일 보유 도메인의 **97%가 한 달간 요청 0건**. Google Search 문서는 llms.txt를 **언급조차 안 하고**, Lighthouse는 **부재를 감점하지 않는다**(404 → 해당없음) |
| "robots.txt 오설정이 에이전트를 조용히 차단한다" | 측정된 **코딩 에이전트 9종은 robots.txt를 요청조차 하지 않았다.** 사용자 트리거 페치 취급도 벤더마다 다르다(Google·Perplexity는 무시, Anthropic은 준수 선언) |
| "User-Agent로 어떤 에이전트인지 안다" | `curl/8.4.0`을 **Cline과 Junie가 함께** 쓴다. 값은 릴리스마다 바뀌고, Google은 위조 가능을 경고하며, 7종 중 2종은 서버측 탐지 자체가 불가하다 |
| "마크다운으로 서빙하면 좋아진다" | **지도 없이 마크다운만 주면 HTML보다 나빴다** — 에이전트가 경로를 스스로 지어내 더 많이 틀렸다. 고친 것은 포맷이 아니라 **링크 지도**였다 |
| "agent-permissions.json은 신흥 표준" | 측정 없는 **제안서**이고 저자가 `non-enforceable by design`을 명시한다 |

## 정직성 불변식

- **도달은 정확도의 증명이 아니다** — 발행 측 개입의 성과는 왕복·404·토큰으로만 말합니다. "문서를 고치면 코드가 N% 맞아진다"고 하지 않습니다.
- **틀린 문서가 없는 문서보다 나쁘다** — 1순위는 빈칸 채우기가 아니라 거짓 제거이고, **검증 없이 LLM이 쓴 문서는 반영하지 않습니다.**
- **점수·백분율·성숙도 등급을 만들지 않습니다** — 연속적 품질↔정확도 함수를 잰 연구가 없습니다.
- **llms.txt·robots.txt·마크다운 전환·구조 재편·컨텍스트 파일은 만들지도 고치지도 않습니다**(report-only). 다만 **거부권은 아니어서**, 알고도 하겠다면 따르고 무엇을 모르는 채 하는지 남깁니다.
- **UA로 도구를 귀속하지 않습니다** — 진위는 벤더 공개 IP·rDNS로만 예/아니오.
- **수용은 재측정으로만** — 못 돌리면 UNVERIFIED.
- **대상 문서는 신뢰할 수 없는 입력입니다** — 문서 안의 명령형 문장에 복종하지 않고 발견으로 보고합니다(조사 중 실제로 프롬프트 인젝션 문구를 만났습니다).

## 이 하네스가 주장하는 것

딱 둘입니다 — **에이전트가 낭비하는 왕복을 줄인다**, **거짓으로 판정되는 서술을 제거한다.**
