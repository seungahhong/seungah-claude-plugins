# 공유 이해 (Phase 5) — 고유정보 펌프

> **판정은 두 갈래다.**
> - **"공유 매체가 집단 이해를 개선한다" → UNSUPPORTED, 방향상 반대 근거가 존재한다.** 커뮤니케이션 매체는 고유정보 풀링에도 결정 품질에도 **영향이 없었다**([evidence.md](./evidence.md) F41, 65연구·3,189집단 메타분석). 그리고 집단은 이미 공유된 정보를 **약 2 SD 과다 논의**한다.
> - **"근거를 외재화한 지속 산출물을 남긴다" → REPORT-ONLY** (메커니즘만, 측정된 효과 없음).
>
> 그래서 이 Phase는 공유 문서를 **더 많이** 만들지 않는다. **한 사람(또는 한 에이전트 실행 기록)만 알고 있고 산출물에서 복원되지 않는 것을 뽑아내는 펌프**로만 설계한다.

---

## 1. 펌프 질문 — 이 Phase의 전부

산출물(코드·PR 본문·커밋 메시지·테스트)에서 **복원되지 않는 것**만 묻는다. 이미 거기 있는 것을 다시 적는 것은 2 SD 과다 논의를 키우는 일이다.

| # | 질문 | 왜 복원 불가능한가 |
|---|---|---|
| **P1** | 이 변경에서 **버려진 대안**은 무엇이고 왜 버렸나 | 코드에는 채택된 것만 남는다 |
| **P2** | 에이전트가 **지시받지 않고 내린 결정** 중 팀이 알아야 할 것은 | 요구에서 유도되지 않으므로 아무 데도 기록이 없다 |
| **P3** | 이 변경이 **가정하는 것** 중 명시되지 않은 것은 | 가정은 코드에 없다 |
| **P4** | 지금 **나만 아는 것**은 무엇인가 | 정의상 팀에 없다 |
| **P5** | Phase 3에서 **내가 틀린 항목** 중 팀도 틀릴 것 같은 것은 | 실측된 함정 |
| **P6** | 아직 **답이 없는 질문**은 | 열린 질문은 1급 산출물이다 |

**P4·P5가 이 Phase의 핵심이다.** 나머지는 보조다.

---

## 2. 공용 이름

이 변경이 만든 **새 이름**(타입·상태·역할·개념)을 목록화하고, 팀이 같은 뜻으로 쓰는지 확인할 대상으로 표시한다.

> **정직성 표기(필수)** — 공유 명명(ubiquitous language)이 성과를 개선한다는 **측정된 효과는 없다.** 메커니즘 서술만 하고 효과를 주장하지 않는다. `[관행]`

---

## 3. 누가 무엇을 알아야 하는가

이 변경이 닿는 영역에 대해 **아는 사람이 몇 명인지**를 관측한다.

- 인기 저장소의 **65%가 truck factor ≤ 2**이고, 개발자의 84%가 주저자 식별에는 동의했으나 **TF 숫자 자체에는 53%만 긍정**했다(F46).
- 따라서 **표적 선정 신호로만 쓰고 건강 점수로 쓰지 않는다.** "이 영역은 TF 1입니다" 같은 등급을 만들지 않는다.
- 출력은 **"이 영역을 아는 사람이 나 말고 있는가? [있음 / 없음 / 모름]"** 3값이다.

---

## 4. 산출물 — 문서보다 상호작용 흔적

| 우선 | 형태 | 근거 |
|---|---|---|
| 1순위 | **팀이 답할 수 있는 열린 질문 목록** | 고유정보를 뽑아내는 유일한 형태 |
| 2순위 | **결정 기록**(대안·버린 이유·가정) | 근거 외재화, REPORT-ONLY |
| 3순위 | 공용 이름 목록 | `[관행]` |
| — | 요약 문서를 하나 더 만드는 것 | **하지 않는다.** 이미 공유된 것의 현저성만 올린다(F41) |

**저자는 자기 설명이 전달되었는지 판단할 최악의 위치에 있다**(F50 — 말하는 사람은 자기가 이해시켰는지를 체계적으로 과대평가한다). 그래서 이 Phase의 산출물은 **선언문이 아니라 질문**이다.

---

## 5. 주장하지 않는 것

- **"공유 문서·스레드가 팀 이해를 개선한다"** — 인과 연구가 존재하지 않는다. 팀 인지–성과 상관은 ρ≈.38이지만 **인과가 아니고** 80% 신뢰구간이 [.17, .59]로 넓다(F42).
- **"팀이 더 정렬됐다"** — 자기보고 결과변수는 효과를 약 2배 부풀린다(F44: 자기보고 r=.77 vs 관찰자 .38). 공통방법편향의 교과서적 서명이다.
- **"transactive memory가 shared mental model보다 낫다"** — **폐기된 결과다.** 2010년의 메커니즘 주장은 두 배 데이터로 **역전**되었다(F43).
- **"사람을 루프에 넣으면 좋다"** — 사람+AI 조합은 평균적으로 최선의 단독보다 유의하게 못했다(F47, g=−0.23, 106개 실험). 이 하네스는 루프에 두는 것 자체를 이득으로 주장하지 않고 **격차를 드러내는 것**만 주장한다.
- **점수·정렬도·성숙도 등급** — 만들지 않는다.

---

## 6. 안티패턴

- **요약 문서를 하나 더 만든다** — 이미 공유된 것의 현저성만 올린다(F41).
- **"팀 정합도가 올랐습니다"라고 보고한다** — 자기보고 인플레다(F44).
- **truck factor를 건강 점수로 쓴다** — 표적 선정 신호까지다(F46).
- **열린 질문 대신 결론을 쓴다** — 저자는 전달 여부를 판단할 최악의 위치다(F50).
- **팀 협업 체계·자율 수준·감독 구조를 설계한다** — 범위 밖이다. 이 Phase는 **이 변경 하나**에 대한 공용 어휘와 열린 질문까지다.
